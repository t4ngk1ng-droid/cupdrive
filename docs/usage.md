# cupdrive 使用说明

**简体中文** | [English](usage.en.md)

> 把视频的节奏翻译成设备动作。全程离线，不联网、不上传视频。

适用设备：**MIZZZEE XW（醉清风）**。其他型号需要先确认协议，见文末。

**版本** v0.3.3 · Windows 10/11 x64

---

## 0. 最短路径（5 分钟）

1. 解压 `cupdrive-win64.zip`，双击 `cupdrive.exe`；
2. 先打开任意视频，再点 **Mock 模式** → **▶**，确认界面能动（不会驱动设备）；
3. 点 **标定台** → 拖入视频 → **⚡ 全自动** → 下载 `<视频名>.script.json`；
4. 回窗口点 **导入脚本**，选刚下载的文件；
5. **扫描设备** → 点 `MIZZZEE XW` → **打开视频** → **▶**。

下面是要理解的细节。第一次用，建议按 1–5 节顺序读。

## 1. 下载与安装

1. 打开仓库的 **Releases** 页面，下载 `cupdrive-win64.zip`。
2. 解压到**有写权限**的目录，例如：
   - `D:\cupdrive\`
   - `C:\Users\你的用户名\Documents\cupdrive\`
   - **不要**放在 `C:\Program Files\`（程序要在旁边写 `curves\`）。
3. 双击 `cupdrive.exe`。

首次启动会出现 Windows SmartScreen 提示（exe 没有代码签名）：

> **更多信息 → 仍要运行**

这是正常的，不是病毒。程序不联网，只监听 `127.0.0.1` 本机回环地址。

启动后：

- 会弹出一个 **Edge 应用窗口**，标题 `cupdrive`；
- 程序目录下自动生成 `curves\`，里面有一条示例曲线 `example.tuned.json`；
- 窗口关闭后，后台进程会在 **2 分钟**内自动退出；也可以点顶栏的 **退出** 立即关闭。

> 如果双击后没有看到窗口：等 5 秒，检查任务栏。仍然没有的话，打开程序目录下的 `cupdrive.log`，最后一行会写 `cupdrive http://127.0.0.1:端口号/`，把地址复制到浏览器即可。

├───────────────────────────────┬──────────────────────────────┤
│                               │ 视频     [打开视频]           │
│                               │ 曲线     [下拉框] + 缩略图     │
│         视频画面               │ 参数     强度/提前量/伸缩滞后  │
│                               │ 通道     振动/伸缩/抖动        │

│ 振动 ████████░░░░  伸缩 ██░░░░░░░░  抖动 ░░░░░░░░░░           │

**顶栏**

| 元素 | 作用 |
|---|---|
| 圆点 + 文字 | 未连接 / 已连接 / Mock |
| `81% 3.00V` | 设备电量、电压（连上后出现） |
| `123 帧` | 已发送的控制帧数 |
| **标定台** | 在浏览器打开曲线编辑器 |
| **导入脚本** | 选标定台导出的 `.script.json`，自动加工成曲线 |
| **扫描设备** | 搜索附近 BLE 设备（约 6 秒） |
| **Mock 模式** | 不连设备，只走完整时序，用来试播放 |
| **退出** | 关闭后台服务 |

**底部**

| 元素 | 作用 |
|---|---|
| ▶ / ❚❚ | 播放 / 暂停 |
| 进度条 | 拖动跳转 |
| **紧急停止** | 立即归零（快捷键 `Esc`） |
| 三条强度条 | 显示当前实际发出的振动 / 伸缩 / 抖动强度 |

## 3. 第一次使用（完整流程）

### 第 1 步：先确认软件能跑

1. 点 **打开视频**，随便选一个本地视频（没有视频时 ▶ 会拒绝播放）；
2. 点 **Mock 模式**（顶栏出现 `Mock`）；
3. 曲线下拉框里选 `example.tuned.json`；
4. 点 **▶**。

底部强度条会跟着 12 秒示例曲线起伏，但不会驱动设备。这一步只是确认界面和时序正常。

### 第 2 步：标定一条自己的曲线

1. 点 **标定台**，浏览器会打开曲线编辑器；
2. 把视频拖进页面（或点「打开视频」）；
3. 点 **⚡ 全自动**：
   - ① 扫描音频响度；
   - ② 按规则合成表现轨；
   - ③ 自动下载 `<视频名>.script.json`。

标定台右上角的 `EN` / `中` 可以切换界面语言，和桌面版共享设置。
4. 文件会出现在浏览器的下载目录。

标定台里的三个手动工具：

| 工具 | 用途 |
|---|---|
| 画笔 | 在强度/表现轨上直接画 |
| 橡皮 | 擦掉画过的部分 |
| 选区 | 对一段区间做整体升降 |

右边有 **撤销**、**保存草稿**（存浏览器本地）、**导出 JSON**。

### 第 3 步：导入并加工

1. 回到 cupdrive 窗口；
2. 点 **导入脚本**；
3. 选中刚下载的 `<视频名>.script.json`；
4. 程序会做降噪 → 百分位拉伸 → 融合 → 限速包络 → 呼吸，然后把 `<视频名>.tuned.json` 放进 `curves\`，并自动选中。

导入成功的提示会显示点数、时长、是否包含画面融合。

### 第 4 步：打开视频

点右侧 **打开视频**，或把视频文件直接拖进左侧黑色区域。

如果曲线里的 `source` 和视频文件名一致，程序会自动选中对应曲线，并提示「已自动匹配曲线」。

### 第 5 步：连接设备

1. **先把手机上的「醉清风」App 彻底杀掉**（不是切后台），最好把手机蓝牙也关掉；
2. 设备开机；
3. 点 **扫描设备**，等 6 秒；
4. 列表里带 ★ 的 `MIZZZEE XW` 就是目标，点它；
5. 顶栏变绿并显示电量，说明连接成功。

### 第 6 步：播放

1. 确认强度滑块在 85% 左右；
2. 点 **▶**，视频开始播放，设备跟着动；
3. 随时可以点 **紧急停止** 或按 `Esc`。

## 4. 参数说明

| 参数 | 范围 | 默认 | 说明 |
|---|---|---|---|
| **强度** | 20–100% | 85% | 曲线整体缩放。第一次用建议 60–70%，熟悉后再加 |
| **提前量** | -500–+1000ms | 0 | 正值让设备提前动作，补偿蓝牙延迟。觉得"慢半拍"就加 100–200ms |
| **伸缩滞后** | 0–2.0s | 0.8s | 只影响伸缩通道：比振动晚多久。0 表示完全同步 |

**快捷键**

| 键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `Esc` | 紧急停止（立即归零） |

## 5. 通道与安全

程序默认**只开振动**。

| 通道 | 上限 | 说明 |
|---|---|---|
| 振动 | 55 | 默认开启 |
| 伸缩 | 40 | 机械行程，**可能夹手**，开启前要确认 |
| 抖动 | 35 | 高频抖动，不是吮吸 |
| 旋转 | — | 本机无此硬件，不提供 |

点击「伸缩」或「抖动」会弹出确认框。这是故意的，不是 bug。

五道安全机制：

1. **通道白名单**：机械通道默认关闭；
2. **硬上限**：即使前端传 100，后端也会压到 40/55/35；
3. **限速**：每秒最多变化 25 个单位，不会瞬间跳变；
4. **异常归零**：暂停、急停、关窗口、进程退出都会先发归零帧；
5. **审计**：命令行模式退出时打印峰值、均值、被限幅次数。

**第一次接新设备**：一次只开一个通道，从 3、5、8、12 这样的小值开始，手离开设备。

## 6. 常见问题

**扫描不到设备**

- 手机 App 没杀干净（最常见）；
- 手机蓝牙还连着设备；
- 设备没电或没开机；
- 距离太远，靠近到 1 米内再扫。

**点设备后连接失败**

- 设备被其他程序占用：杀掉手机 App、关掉其他控制软件；
- 设备重启一次；
- 仍然失败时，先点 **Mock 模式** 排除软件问题。

**设备动了但很弱**

- 强度滑块太低（默认 85%，可以往上）；
- 曲线本身太平：回标定台，点「扫描」后手动把强度轨画高一点，再导入；
- 通道上限就是 55（振动），不会到 100。

**设备完全不动**

- 确认顶栏是「已连接」而不是「Mock」；
- 确认底部「振动」强度条在动；
- 有些设备需要先按一下机身上的电源键唤醒。

**播放时没有视频声音**

- 不要静音视频（静音会让音频分析失效，也会让体验变差）；
- 检查系统音量。

**视频和曲线长度不一致**

- 正常。曲线比视频长时，超出部分发 0；曲线短时，视频后半段设备静止。
- 建议用同一条视频重新标定。

**关闭窗口后进程还在**

- 正常，最多 2 分钟后自动退出；
- 想立刻退出：重新打开窗口点 **退出**，或任务管理器结束 `cupdrive.exe`。

**窗口没弹出来**

- 等 5 秒；
- 打开程序目录的 `cupdrive.log`，找到 `http://127.0.0.1:端口/`，用浏览器打开；
- 检查系统是否安装了 Edge 或 Chrome（Windows 10/11 一般自带 Edge）。

## 7. 从源码运行（开发者）

需要 Python 3.10+（bleak 3.1 的要求）。发布包内置 Python 3.12，普通用户直接双击 `cupdrive.exe`，不需要安装 Python。

```bash
pip install -r requirements.txt
python webapp.py
```

或者双击 `cupdrive.cmd`（Windows）。

常用参数：

```bash
python webapp.py --check              # 后端自检，不开窗口
python webapp.py --selftest           # 启动服务并调 API，跑完退出
python webapp.py --no-browser         # 只启动服务
python webapp.py --port 8123          # 固定端口
python webapp.py --debug              # 打印 HTTP 请求
```

命令行播放（不经过界面）：

```bash
python -m cupdrive.play curves/example.tuned.json --backend ble --wait
```

打包发布：

```bat
release.bat
```

产物在 `release\cupdrive-win64.zip`。

## 8. 支持其他设备

目前只对 `MIZZZEE XW` 做过逐字节验证。其他设备需要：

1. 抓一份广播名；
2. 用 `tools/channel_probe.py` 确认 service / write / notify；
3. 修改 `cupdrive/protocol.py` 里的 UUID 表；
4. **一次只开一个通道**，从小值开始试。

协议笔记见 [`protocol.md`](protocol.md)，安全设计见 [`safety.md`](safety.md)。
